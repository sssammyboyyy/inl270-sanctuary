## 🌿 Overview

An Apple-grade, tranquil, multi-sensory study simulator designed for high-leverage conceptual mastery. Engineered for neurodivergent learners (ADHD) with zero friction, anti-anxiety sensory design, and experiential scenario analysis.

### Features
* **8 Paradigm Sliders:** Dual-lens toggle contrasting Western Cartesian reductionism with Indigenous relational ontology.
* **10 High-Yield Exam Dilemmas (POV Mode):** Step into real case studies with interactive choices, "Examiner's Lens" breakdowns, and rubric keywords.
* **The Essay Forge:** Interactive blueprint for the compulsory long essay with 1-tap clipboard copying to Apple Notes.
* **Sensory Design:** Web Audio API synthesized $432\text{ Hz}$ Tibetan singing-bowl chimes + Safari Web Speech voice narrator.
* **PWA & Offline Ready:** Add to iPhone/iPad Home Screen for full-screen native experience.
